# ГолосКалендар · Android

Повний проєкт для Android Studio. Створюйте подію з української фрази й зберігайте її у власному локальному календарі ГолосКалендаря. Переглядайте місяць і події дня, редагуйте та видаляйте зустрічі. За потреби подію можна окремо відкрити в системному календарі.

**Версія 4.1.0 · Android 8.0+ (64 біти) · Java 17 · Gradle 8.9 · Android SDK 35**

[Готовий APK і повний проєкт ZIP](https://github.com/salenko93-hash/HolosCalendar-Download)

## Локальний український голос — 4.1.0

Додано Whisper на телефоні, без залежності від сервісу Google у локальному режимі. Встановіть один раз багатомовну Tiny або Base через екран голосу; запишіть команду до 30 секунд і перевірте текст у формі. Модель завантажується окремо, у ZIP/APK її немає. Для завантаження на ПК є `DOWNLOAD_MODEL.ps1`.

[Повна інструкція, сумісність, походження моделей і перевірки](docs/OFFLINE_SPEECH.md). Після імпорту локальне розпізнавання не потребує мережі; аудіо не зберігається. Системний режим доступний окремо. Це готова попередньо навчена модель; власного донавчання поки немає. APK підтримує arm64-v8a та x86_64.

## Відкрити на своєму ПК

1. Завантажте ZIP цієї гілки через GitHub → **Code → Download ZIP** та розпакуйте його.
2. В Android Studio виберіть **Open** і відкрийте папку з `settings.gradle`.
3. У **Settings → Build, Execution, Deployment → Build Tools → Gradle** виберіть **Gradle JDK 17**. Потрібен повний JDK, не лише JRE.
4. У **SDK Manager** встановіть **Android SDK Platform 35**, **Android SDK Build-Tools 34.0.0** та **Android SDK Platform-Tools**, **NDK 27.2.12479018**, **CMake 3.22.1**. Прийміть ліцензії SDK.
5. Дочекайтеся Gradle Sync. Підключіть Android-телефон із USB debugging або запустіть емулятор та натисніть **Run** для модуля `app`.

Глобально встановлювати Gradle не потрібно: `gradlew`, `gradlew.bat` і перевірений Wrapper JAR включено. Завантаження Gradle захищене SHA-256.

### Windows PowerShell

```powershell
.\gradlew.bat --no-daemon assembleDebug lintDebug testDebugUnitTest
```

### Linux / macOS

```sh
./gradlew --no-daemon assembleDebug lintDebug testDebugUnitTest
```

Поза Android Studio задайте `JAVA_HOME` на JDK 17, а `ANDROID_HOME` — на встановлений SDK, або створіть локальний `local.properties` із `sdk.dir`. Не додавайте цей файл у Git.

**APK:** `app/build/outputs/apk/debug/app-debug.apk`.
**Тести:** `app/build/reports/tests/testDebugUnitTest/index.html`.
**Lint:** `app/build/reports/lint-results-debug.html`.

## Як користуватися

1. На головному екрані календаря виберіть день. Стрілки перемикають місяці, **Сьогодні** повертає поточний день. Позначка під числом означає наявність подій.
2. Натисніть **Додати подію голосом або текстом**. Вибрана дата вже є у формі; можна заповнити поля вручну або продиктувати/розпізнати всю фразу. Розбір застосовує дату з фрази; за її відсутності дату потрібно вибрати вручну.
3. Перевірте назву, дату, час і тривалість. Без названої тривалості поле показує **Тривалість: не вказано**. Її можна вибрати або прибрати вручну.
4. Натисніть **Зберегти в ГолосКалендарі**. Подія зберігається на телефоні, і відкривається її день у календарі. **Редагувати** відкриває ту саму подію; **Оновити подію** змінює її без створення дубля. **Видалити** запитує підтвердження.
5. Для зовнішнього календаря є окрема кнопка **Відкрити в системному календарі**. Вона відкриває редактор, у якому потрібно самостійно підтвердити збереження. Автоматичної синхронізації немає.

Зміна вихідної фрази потребує повторного розбору: застосунок не збереже й не передасть старі деталі мовчки. Поворот екрана зберігає форму, обрану тривалість і статус. **Очистити форму** запитує підтвердження та не видаляє збережені зустрічі.

## Підтримувані фрази

| Фраза | Результат |
|---|---|
| Завтра о 14:30 Зустріч у Києві | Завтра, 14:30; назва зберігає регістр і прийменник |
| 05.11 о 9 Нарада | Найближче 5 листопада, 09:00 |
| 25 жовтня 2027 о 14.30 Зустріч | 25.10.2027, 14:30 |
| У понеділок о 9 Дзвінок | Найближчий понеділок (включно із сьогодні), 09:00 |
| Через годину Перерва | Через щонайменше 60 хвилин, з округленням угору до хвилини |
| Через 30 хвилин Дзвінок | Через щонайменше 30 хвилин, з переходом дати за потреби |
| Через пів години Перерва | Через 30 хвилин; тривалість не вказана |
| Завтра о 15:00 Зустріч з Оленою на 30 хвилин | Завтра, 15:00; тривалість 30 хвилин |
| Завтра о 15 Нарада на годину 30 хвилин | Завтра, 15:00; тривалість 90 хвилин |
| Через годину Дзвінок на пів години | Початок через годину; тривалість 30 хвилин |

- Тривалість розпізнається за явною вказівкою «на», «тривалістю», «триватиме», «протягом» або окремою кількістю з одиницею («30 хв», «півгодини»): числові хвилини/години, поширені словесні кількості, пів години, півтори години та години з хвилинами. Межі: 1–1440 цілих хвилин. Кілька тривалостей або некоректне значення залишають поле незаповненим із повідомленням. «Через годину» задає початок, а не тривалість. Новий розбір не переносить тривалість із попередньої фрази.
- Без тривалості додаток передає календарю лише час початку, без часу завершення. Зовнішній календар може запропонувати власну тривалість — перевірте його редактор.
- Підтримуються сьогодні, завтра, післязавтра та всі дні тижня.
- Дата без року — найближча майбутня або сьогоднішня; 29 лютого шукається у найближчому відповідному високосному році.
- «Наступного понеділка» — на тиждень пізніше найближчого понеділка (включно із сьогодні).
- Дата `05.11` сама по собі не задає час. Дробовий час із крапкою потребує прийменника: `о 14.30`.
- Некоректні чи відсутні дата/час не підставляються. Кілька розпізнаних дат або часів потребують ручного вибору.
- Словесний час і частини доби підтримуються: «о другій дня» → 14:00, «о дев’ятій вечора» → 21:00. Без частини доби, наприклад «о сьомій», потрібен вибір 07:00 або 19:00. Приблизні значення потребують підтвердження. Повторення та цілоденні події описані нижче.
- Нові події використовують часовий пояс телефона; збережені серії та цілоденні події зберігають свій первісний пояс. Неіснуючий час під час весняного переходу заблоковано; для введеного вручну або абсолютною фразою повторюваного осіннього часу запитується згода на перше входження. Для відносного часу точний момент уже відомий і зберігається.

## Природна українська, серії та цілоденні події: 4.0.0

- «За півгодинки» задає початок через 30 хвилин; «на пів години» — тривалість. Неназвана тривалість залишається порожньою.
- «З другої до третьої дня» → 14:00, 60 хв; «з 14:00 по 15:30» → 14:00, 90 хв. Словесний проміжок без часу доби потребує уточнення.
- «Через три дні», «за тиждень», «першого листопада», «в останній день місяця» задають точні дати. «Наприкінці місяця» та «наступного року» потребують вибору точної дати.
- «Щовівторка», «по буднях», «раз на два дні», «щомісяця першого числа», «щороку 15 травня» створюють серію. «Через день», «двічі на тиждень» та «кожного другого вівторка» потребують уточнення правила. Є ручний вибір днів, інтервалу у два тижні та порядкового дня тижня у місяці.
- «В останню неділю місяця» без «щомісяця» — одна найближча дата з підтвердженням. Для серії додайте «щомісяця» або оберіть повторення.
- «На весь день» та «з п’ятого по десяте листопада» створюють цілоденну подію (5–10 включно), без штучної тривалості чи часу початку. Для її сповіщення вибирається окремий точний час.
- «Нагадай» / «постав нагадування» обирає нагадування у час початку. Воно працює після локального збереження й надання дозволів Android.
- Редагування та видалення стосуються **всієї серії**; винятків для одного повтору немає. Події серії зберігають місцевий час у первісному поясі після переходу годинника. Неіснуючий весняний час, місяць без потрібного числа та невисокосні роки для 29 лютого пропускаються.

[Довідник українських фраз](docs/UKRAINIAN.md). [Критичний огляд і наступні покращення](docs/REVIEW-4.0.0.md). У гілці готової збірки також є **HolosCalendar-Ukrainian-4.1.0.pdf** з усіма 87 прикладами та поясненнями. PDF генерується з тієї самої таблиці, що й тести:

```sh
python3 -m pip install -r tools/requirements-pdf.txt
python3 tools/build_language_guide.py HolosCalendar-Ukrainian-4.1.0.pdf
```

Потрібні шрифти DejaVu Sans за шляхом `/usr/share/fonts/truetype/dejavu` (Linux: пакет `fonts-dejavu-core`).

GitHub → **Actions → Build HolosCalendar Android APK → Run workflow**. Після успішного запуску у **Artifacts** доступні:

- **HolosCalendar-debug-APK** — APK для телефона;

## Дані й обмеження

Немає власного сервера, API-ключів, акаунтів, аналітики чи постійної історії голосових команд. Збережені події (назва, початок, часовий пояс, необов’язкова тривалість і нагадування) лежать у приватній SQLite-базі `holoscalendar.db` на телефоні. Закриття чи перезапуск застосунку їх не видаляє. Позначка виконаного нагадування запобігає повторним сповіщенням після перезапуску. Очищення даних або видалення застосунку видаляє локальні події; хмарне резервне копіювання вимкнене.

Додаток не читає системний календар і не записує до нього напряму. Для локального голосу запитує RECORD_AUDIO тільки перед записом. Після встановлення моделі локальний режим не використовує мережу; дозвіл INTERNET відсутній, аудіо не зберігається. В окремо обраному системному режимі голос обробляє встановлений сервіс Android, який може використовувати інтернет. Текст і власний календар працюють без мережі. Імпорт, експорт та синхронізація поки не реалізовані.

День і звичайні зустрічі відображаються в поточному часовому поясі телефона. Серії обчислюються у своєму первісному поясі; цілоденні дати залишаються тими самими навіть після зміни поясу. Зустріч із заданою тривалістю, що переходить через північ, відображається в обох днях; зустріч без тривалості — лише в день початку. Подія, що закінчується рівно опівночі, не додається до наступного дня.

Це **debug-збірка**, не підписаний реліз для Google Play. Не зберігайте ключі підпису в репозиторії. Різні debug-ключі можуть заважати встановленню поверх попередньої збірки; спершу перевірте повідомлення інсталятора.

Перевірки на реальному пристрої: [TESTING.md](TESTING.md). Структура: [ARCHITECTURE.md](ARCHITECTURE.md). Рішення інтерфейсу: [DESIGN.md](DESIGN.md).

## Голосовий пошук недоступний

Версія 3.0.1 дозволяє системному розпізнавачу використовувати мережу замість запиту на перевагу офлайн-режиму. Це допомагає уникнути залежності від наявності офлайн-моделі української; доступність розпізнавання на конкретному телефоні все одно визначає системний сервіс.

Якщо вікно Google показує «Голосовий пошук недоступний»:

1. Перевірте інтернет і спробуйте голосове введення українською безпосередньо в Google або Gboard.
2. У налаштуваннях застосунків перевірте дозвіл на мікрофон для Google. Це стосується системного режиму; локальний режим має окремий дозвіл мікрофона для ГолосКалендаря.
3. Оновіть Google і встановлений сервіс розпізнавання мовлення через Play Store, перевірте підтримку української.
4. Повторіть диктування. Якщо зовнішній розпізнавач досі недоступний, можна заповнити подію текстом або вручну.

Оновлений APK збирайте на тому самому ПК для збереження попереднього debug-підпису. Якщо використовували інший ключ, Android може відхилити оновлення поверх старого APK.

## Виправлення закриття після запису: 3.0.2

Видалено прапорець `Pattern.UNICODE_CHARACTER_CLASS`, який Android відхиляє з `IllegalArgumentException: Unsupported flags: 256`. Ця помилка виникала під час першої ініціалізації парсера після голосового або текстового введення; на настільному JDK прапорець підтримується, тому попередні JVM-тести проходили.

Для перевірки Android-реалізації додано `SpeechResultTest`: він передає в Activity готовий результат розпізнавання, перевіряє заповнення форми, скасування, порожній результат і перестворення екрана. Це не тест самого сервісу Google чи мікрофона.

На підключеному Android-пристрої або запущеному емуляторі:

```powershell
.\gradlew.bat connectedDebugAndroidTest
```

Звіт: `app/build/reports/androidTests/connected/debug/index.html`. Голосову службу та мікрофон перевірте додатково на телефоні за TESTING.md.

## Перевірена версія 3.0.3

Знайдені помилки, їхні приклади й виправлення: [REVIEW-3.0.3.md](REVIEW-3.0.3.md).

- Дні й роки не обрізаються до випадково коректних значень; `125 жовтня` та `20270` потребують виправлення.
- «На 05.11» означає дату, «на 05:11» — час. Прийменники, нерозривні пробіли та українські апострофи обробляються узгоджено.
- «Через хвилину» округляється вгору, щоб подія не наставала раніше ніж за хвилину. Відносний час враховує реальний перебіг часу через DST; після зміни часового поясу зберігається той самий момент.
- Повернення вихідної фрази до останнього розібраного тексту зберігає ручні виправлення й не вимагає повторного розбору.
- Голосова команда понад 1000 символів відхиляється без зміни форми; назви до 1000 символів не обрізаються на 200.
- Час доби («о 9 вечора») потребує ручного вибору у 24-годинному форматі; додаток не підставляє 09:00.
- Версія показана у вікні «Як це працює». APK і проєкт у Actions публікуються лише після JVM/lint та Android-завдань.

## Тривалість без підстановки: 3.0.4

Прибрано автоматичні 60 хвилин у формі та прихований час завершення під час переходу в календар. Тривалість заповнюється з явної вказівки у фразі або після ручного вибору. У списку є «Не вказано» для скидання. Новий розбір без тривалості й очищення форми прибирають попереднє значення; перестворення екрана зберігає як вказане, так і порожнє поле.

Готовий debug APK і ZIP із проєктом та APK публікуються в окремій гілці [holoscalendar-apk-3.0.4](https://github.com/salenko93-hash/HolosCalendar-Android/tree/holoscalendar-apk-3.0.4). Його підпис відрізняється від debug-ключа іншого ПК: для оновлення поверх власної попередньої збірки перебудуйте проєкт на тому самому ПК. Це не реліз для Google Play; походження збірки й контрольні суми записані в README гілки з APK.

У ZIP зі зібраного пакета готовий інсталятор лежить у `APK/HolosCalendar-3.0.4-debug.apk`; відкривайте папку `HolosCalendar` в Android Studio. Звичайний GitHub Code → Download ZIP містить лише вихідні файли.

## Власний календар та іконка: 3.1.0

Новий стартовий екран — місячний календар із вибором дня та списком зустрічей. Додано локальне збереження, редагування й видалення; форма та повернення до вибраного місяця зберігаються після перестворення екрана. Основна дія форми тепер зберігає у ГолосКалендарі, зовнішній календар залишається окремою дією.

Нова іконка з календарем і мікрофоном використовується в launcher та в заголовках обох екранів. Для Android із тематичними іконками передбачено монохромний варіант.

Актуальні APK і ZIP: [holoscalendar-apk-3.1.0](https://github.com/salenko93-hash/HolosCalendar-Android/tree/holoscalendar-apk-3.1.0). У ZIP готовий інсталятор: `APK/HolosCalendar-3.1.0-debug.apk`. Підпис хмарної збірки збережено для оновлення 3.0.4; `versionCode` підвищено до 8.

## Нагадування про події (додані у 3.2.0)

1. У формі події натисніть **Нагадування** та виберіть: у час початку, за 5, 10, 15, 30, 60 хвилин або за день (24 години). Нові та раніше збережені події за замовчуванням мають нагадування **Вимкнено**.
2. На Android 13+ дозвольте сповіщення. Якщо раніше відмовили або вимкнули канал, відкрийте **Налаштувати сповіщення** у формі чи внизу календаря. Події можна зберігати й без дозволу; форма та календар пояснюють, що нагадування заблоковані.
3. На Android 12+ для точного спрацювання натисніть **Точний час** у цьому діалозі й дозвольте будильники/нагадування в Android. Без цього дозволу застосунок використовує доступне планування, але Android може затримати доставку.
4. Натисніть **Зберегти в ГолосКалендарі** або **Оновити подію**. Незбережена форма та відкриття системного календаря не створюють локального нагадування.
5. Сповіщення показує назву й початок події; натискання відкриває саме цю зустріч. На заблокованому екрані використовується приватна видимість із загальним текстом без назви зустрічі, з урахуванням налаштувань Android.

Редагування часу чи нагадування переплановує його, вимкнення та видалення події прибирають його з черги. Оновлення назви вже сповіщеної події не створює повторного нагадування. Після перезавантаження, оновлення APK та зміни системного часу черга відновлюється з бази. Перехід часових поясів чи DST не змінює абсолютний момент зустрічі.

Якщо час нагадування минув, але зустріч ще попереду, воно надходить одразу. Допускається доставка до п’яти хвилин після початку, щоб невелика системна затримка не втратила нагадування; старіші зустрічі не відтворюються. Тиша, звук і вібрація залежать від каналу сповіщень, режиму «Не турбувати» та налаштувань телефона. Примусова зупинка застосунку в Android вимикає його нагадування до повторного запуску.

База переходить зі схеми 1 на 2 через ALTER TABLE зі збереженням усіх зустрічей; нагадування для старих записів не вмикаються автоматично.

## Перевірка 4.1.0

190 JVM-тестів, 56 Android-тестів на API26, 3 хостові перевірки реального JNI/Whisper Base (українське аудіо, таймаут, скасування/закриття).
