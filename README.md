# ГолосКалендар 4.4.0 — без мовних моделей

Android 8.0+ · Java 17 · Gradle 8.9 · Android SDK 35 · versionCode 15.

Текстовий і ручний календар із нагадуваннями. Застосунок не записує звук, не викликає системного голосового розпізнавання, не використовує акустичних чи великих мовних моделей. Немає завантаження ваг, NDK/CMake, C++-бібліотек або дозволів мікрофона й інтернету. Підтримуються як 32-бітні, так і 64-бітні Android-пристрої.

Перевірено: 223 JVM-тести та 64 Android-тести на API26, lint без зауважень. Деталі — у [TESTING.md](TESTING.md). Фізичний Redmi та API35 локально ще не перевірені.

Українські фрази розбираються локально явними правилами й регулярними виразами. Це звичайний програмний парсер, без навчання або серверного API.

## Нові українські текстові команди

Додано 35 прикладів до спільного набору з 122 фраз для тестів і PDF. Збережено попередні формулювання.

| Фраза | Результат |
|---|---|
| Через годину і двадцять хвилин Дзвінок | Початок через 80 хвилин, без вигаданої тривалості |
| У середу наступного тижня Зустріч | Середа наступного календарного тижня |
| Через місяць Перевірка | Те саме число наступного місяця; останній день за відсутності числа потребує підтвердження |
| Кожні три дні о 15:00 Тренування | Одна серія з інтервалом 3 дні |
| Щопонеділка та щосереди о 15:00 Нарада | Одна серія у два дні тижня |
| О дев’ятій годині ранку Дзвінок | 09:00 |
| Пів дев’ятої Зустріч | Вибір 08:30 або 20:30 |
| Будь ласка, нагадайте мені завтра о 9 зателефонувати мамі | Завтра 09:00, нагадування у час початку |

Тиждень починається в понеділок. «Цього тижня» може означати минулу дату поточного тижня — перед збереженням застосунок попросить підтвердити минулу подію. «Через пів місяця» не задає точного числа днів; дата потребує ручного вибору.

Опис понад 1000 символів тепер зберігається у полі повністю. Застосунок просить скоротити його перед розбором або збереженням і не перезаписує попередні деталі обрізаним текстом.

## Як користуватися

1. У календарі оберіть день → **Додати подію**.
2. Введіть, наприклад, «Завтра о 14:30 зустріч у Києві на 45 хвилин» → **Розібрати текст**. Або одразу заповніть поля вручну.
3. Перевірте назву, дату, час, тривалість і повторення. Без названої тривалості поле залишається порожнім. Неоднозначні значення потребують вибору.
4. За потреби оберіть **Нагадування**: у час початку, готовий інтервал або довільні 0–1440 хвилин до початку. Для цілоденної події потрібен окремий час нагадування.
5. **Зберегти в ГолосКалендарі** або **Оновити подію**. Відкриття зовнішнього календаря є окремою дією і не створює локальне нагадування.

**Налаштувати сповіщення → Перевірити сповіщення** показує тестове повідомлення. Для Android 13+ дозвольте сповіщення, для Android 12+ за потреби ввімкніть точний час. Звук, затримки, Doze й обмеження Redmi залежать від системи. Примусова зупинка блокує нагадування до наступного запуску застосунку.

## Оновлення та видалення старої моделі

Під час першого запуску 4.4.0 у фоновому потоці видаляє старий приватний каталог `files/speech`, включно з імпортованою моделлю й тимчасовими імпортами, та попередні голосові налаштування. Символічні посилання не обходяться. Календар і нагадування залишаються; SQLite-схема 3 не змінена. Якщо видалення не вдалося, застосунок повторює його під час наступного запуску.

Оригінальний .bin, який ви самі завантажили в загальну папку **Завантаження**, не належить до приватних файлів застосунку. Якщо він більше не потрібен, видаліть його через «Файли» на телефоні. Він не використовується 4.4.0.

Хмарний APK має той самий debug-підпис, що й попередні хмарні APK. Якщо встановлену версію ви збирали на ПК іншим ключем, зберіть нову на тому самому ПК з тим самим ключем. Не видаляйте застосунок для звичайного оновлення: очищення даних/видалення стирає особистий календар. Експорту та синхронізації поки немає.

## Відкрити на ПК та зібрати

Розпакуйте повний ZIP і відкрийте папку **HolosCalendar** в Android Studio. Потрібні JDK 17 та SDK 35; додаткові моделі, NDK і CMake не потрібні. Gradle Wrapper включений.

Windows PowerShell:

```powershell
.\gradlew.bat --no-daemon assembleDebug lintDebug testDebugUnitTest
```

Linux/macOS:

```sh
./gradlew --no-daemon assembleDebug lintDebug testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Це debug-збірка для перевірки. Ключі підпису до проєкту не включаються.
