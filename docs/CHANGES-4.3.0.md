# ГолосКалендар 4.3.0 — без мовних моделей

- Повністю видалено інтеграцію Whisper, JNI/C++ і сторонні джерела, запис та обробку аудіо, локальні ваги й завантажувач. Моделей у проєкті та APK немає.
- Видалено також виклик системного голосового розпізнавання, щоб застосунок не використовував зовнішню мовну модель замість прибраної.
- Прибрано екран встановлення моделей, голосовий режим, кнопки запису й дозволи мікрофона. Немає дозволу INTERNET.
- Подія створюється текстом українською через «Розібрати текст» або ручним заповненням. Правила української, неоднозначності, необов'язкова тривалість, власний календар, серії та нагадування збережені.
- Додано автоматичне очищення колишніх приватних моделей і тимчасових імпортів під час запуску. Очищення працює у фоні та не видаляє подій, нагадувань або інших файлів. Символічні посилання не обходяться. Помилка очищення не закриває застосунок; спроба повториться під час наступного запуску.
- Оригінальний .bin у спільній папці «Завантаження», якщо він лишився, потрібно видалити вручну через «Файли». Нова версія його не читає.
- Прибрано NDK/CMake та обмеження на 64-бітні ABI. Для Android Studio достатньо JDK 17, SDK 35 та Gradle Wrapper.
- Application ID та хмарний debug-підпис збережено, versionCode підвищено до 13. База лишається схеми 3, старі зустрічі та налаштування нагадувань зберігаються під час оновлення тим самим ключем. Видалення застосунку/очищення даних стирає календар.

Перевірки: див. TESTING.md і XML-звіти у повному ZIP. На фізичному Redmi ще потрібна перевірка оновлення, звук/Doze, системні дозволи сповіщень і поведінка обмежень живлення. Редагування серій змінює всю серію; експорту та синхронізації поки немає.
