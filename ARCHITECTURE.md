# Архітектура 4.3.0

Нативний Android SDK/Java, minSdk 26, target/compileSdk 35, Java 17, Gradle 8.9, AGP 8.7.3. Немає C++, JNI, NDK, моделей або runtime-залежностей ML. JUnit та AndroidX Test потрібні лише для перевірок. Application ID `ua.holoscalendar.redmi`, versionCode 13; для оновлення потрібен той самий підпис.

- `CalendarActivity` показує місячну сітку й події дня. Читає SQLite у власному робочому потоці, застосовує лише актуальний результат. Launcher alias `.MainActivity` зберігає сумісність ярликів.
- `EventEditorActivity` приймає текст або ручні поля. Зміна опису потребує повторного розбору перед збереженням. Bundle зберігає форму, ручні правки й ID під час перестворення.
- `EventTextParser` / `UkrainianParser` розбирають текст правилами. `CalendarEvent` перевіряє час, дату, тривалість та DST. Жодної акустичної або мовної моделі тут немає.
- `EventStore` зберігає події у приватній SQLite-базі `holoscalendar.db`, схема 3. Міграції зі схем 1 і 2 збережено. Невідома тривалість є null.
- `RecurrenceRule` / `OccurrenceEngine` обчислюють входження серій у потрібному часовому вікні. Редагування й видалення змінюють усю серію; окремих винятків поки немає.
- `ReminderPolicy` обчислює час нагадування. `ReminderScheduler` ставить один системний сигнал і обробляє всі готові нагадування. Транзакційний claim відкидає дублікати, видалені та перенесені події. `ReminderReceiver` відновлює чергу після перезапуску/оновлення/зміни годинника.
- `ReminderAccess` керує каналом, дозволами, налаштуваннями та окремим тестовим повідомленням. Без точного доступу використовується неточний сигнал із поясненням можливої затримки.
- `HolosApplication` запускає `LegacySpeechCleanup` у фоновому потоці. Міграція видаляє лише колишній приватний каталог `files/speech` і налаштування `speech`, без обходу символічних посилань і без доступу до календаря чи загальних завантажень. Після невдачі повторюється при наступному старті.

Текст, календар і нагадування працюють без інтернету. Дозволів RECORD_AUDIO та INTERNET немає. Системне голосове розпізнавання не викликається. Відкриття зовнішнього календаря — лише ACTION_INSERT із підтвердженням у його редакторі; синхронізації немає. Хмарне резервне копіювання вимкнене, експорт особистих подій ще не реалізовано.
