# Огляд завантаженої версії 3.0.2 та виправлення 3.0.3

Вхідний ZIP побайтово збігся з усіма 40 файлами commit `66c1c8964fc66b6aa1629ae71f4acc652cf7c49a`. Інструкції всередині архіву розглядалися як документація проєкту.

## Підтверджені проблеми та зміни

| Проблема у 3.0.2 | Приклад / наслідок | Виправлення |
|---|---|---|
| Некоректні дні й роки обрізалися до коректних | «125 жовтня» → 25 жовтня; `20270` → `2027` | Повний розбір числового компонента й перевірка його довжини; некоректна дата потребує ручного вибору |
| Дата з прийменником могла стати часом | «на 05.11» → 05:11; «Нарада на завтра» залишала зайве «на» | Крапка після «на» належить даті; прийменники вилучаються лише разом із часовим фрагментом |
| Звичайні варіанти українського вводу не оброблялися однаково | `пʼятницю` з U+02BC; нерозривний пробіл після «о» | Підтримка трьох апострофів і нормалізація Unicode-пробілів на JVM та Android |
| Відносний час округлявся вниз | О 10:00:59 «через хвилину» давало 10:01 — лише через секунду | Округлення вгору до наступної хвилини, щоб подія не наставала раніше запитаного проміжку |
| Відносний час рахувався за місцевим годинником під час DST | Kyiv 25.10.2026 о 03:30 першого входження: «через годину» давало подію через дві реальні години | Обчислення через ZonedDateTime, збереження точного Instant, правильного входження й відновлення після зміни часового поясу |
| Позначення часу доби ігнорувалося | «о 9 вечора» ставало 09:00 | Непідтримуваний час доби явно потребує ручного вибору; додаток не припускає AM/PM |
| Зайве блокування після повернення початкового тексту | Редагування фрази й повернення її назад вимагало повторного розбору, який перезаписував ручну назву | Порівняння з останньою розібраною фразою, зі збереженням стану після перестворення Activity |
| Голосові команди й назви мовчки обрізалися | Команда понад 1000 символів оброблялася лише частково; назва понад 200 втрачала закінчення | Наддовга команда відхиляється зі збереженням форми; назва підтримує повний текст до 1000 символів |
| Статус помилки не оновлювався після ручного вибору дати/часу | Обрана дата вже є, а текст досі просить її обрати | Повторна оцінка готовності полів після вибору |
| Actions публікував APK до завершення Android-тестів | Готовий артефакт міг існувати навіть після падіння runtime-тесту | Окремий job пакування, який залежить від JVM/lint і обох Android-завдань |

У довідці додатка тепер показано версію, щоб можна було перевірити, який APK установлено.

## Критика та наступні кроки

- Парсер залишається набором правил для однієї події. Словесні години, час доби, повторення та кілька подій потребують окремого узгодженого формату й тестів. Поточна версія просить уточнення, коли не може безпечно визначити час доби.
- MainActivity досі поєднує форму, стан і зовнішні інтеграції. Для наступного розширення варто винести стан форми й побудову intent в окремі класи, зберігши Android-тести як захист від регресій.
- Великий вступ займає суттєву частину першого екрана. Для частого використання доцільний компактний режим із голосовою кнопкою та деталями вище; це зміна дизайну, а не виправлення парсера.
- Голосове введення залежить від установленого сервісу Google/Android, а збереження — від редактора календаря. Тести обробки результату не замінюють перевірку мікрофона й фактичного збереження події на телефоні.

## Перевірка

Команди та результати наведено в TESTING.md і README.md. Звичайні тести, Android-тести, lint, підпис APK та склад ZIP перевіряються окремо. Проходження тестів на API 26 не є підтвердженням запуску на всіх моделях телефонів; окремі CI-завдання перевіряють API 26 і 35.

### Результати цієї збірки

- `assembleDebug`, `assembleDebugAndroidTest`, `lintDebug`, `testDebugUnitTest`: успішно.
- JVM: 55 виконаних тестів, 0 помилок, 0 пропущених.
- Android: 9 виконаних тестів на Android 8.0 / API 26, 0 помилок, 0 пропущених. Прогін включає фінальне виправлення часу доби.
- Lint: `No issues found`.
- APK: версія 3.0.3, versionCode 6, minSdk 26, targetSdk 35; підпис v2 перевірений `apksigner`, вирівнювання перевірене `zipalign`.
- API 35 не запускався локально; для нього налаштовано окремий CI-прогін. Справжній мікрофон і зовнішній календар потребують перевірки на телефоні.
